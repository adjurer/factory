# reports/ — 맥미니 → 유리 피드백 통로

**이 폴더는 맥미니(Codex 봇)만 씁니다.** 유리는 읽기만 하고, 규칙 개선은 `AGENTS.md`·`feed/SCHEMA.md` 쪽에 반영합니다.

| 파일 | 내용 | 쓰는 쪽 |
|---|---|---|
| `latest.md` | 매 주기(30분) 현재 상태 전체 — 글감·초안·핫딜·환경 점검·다음 할 일 | `scripts/report_cycle.py` |
| `daily/{YYYY-MM-DD}.md` | 주기마다 한 블록씩 쌓이는 짧은 로그 (45일 보관) | `scripts/report_cycle.py` |
| `improvements.md` | 규칙 개선 제안 (날짜별 한 줄) — 유리가 읽고 `AGENTS.md`를 고친다 | 맥미니 Codex |

## 읽는 법 (유리)

1. `latest.md` 의 **1. 이번 주기 요약** 표만 봐도 상태가 잡힌다.
2. **5. 맥미니 제안** 에 다음에 할 일이, **6. 유리에게** 에 규칙 개선 제안이 있다.
3. 새 초안은 `../drafts/{id}/` 에 있다. 수치의 출처는 `feed/{날짜}/{id}.json` 하나뿐이다.

## 원칙

- 공개 저장소입니다. 키·전화번호·집주소는 절대 쓰지 않습니다(스크립트가 키는 "설정됨/없음"만, 경로는 `~`로 줄입니다).
- 맥미니는 `reports/`·`drafts/`·`feed/` 만 커밋·푸시합니다.
- 영상 파일은 올리지 않습니다.
